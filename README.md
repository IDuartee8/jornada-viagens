## 📌 Sobre o projeto

O **Jornada Viagens** é um projeto estático apresentando pacotes de viagens nacionais e internacionais, desenvolvido com o objetivo de colocar em prática conceitos fundamentais de front-end, com atenção especial à experiência do usuário em diferentes tamanhos de tela.

## 🎯 Objetivos de aprendizado

- Estruturação semântica de páginas com HTML5
- Estilização e organização de layout com CSS3
- Construção de interfaces **responsivas**, adaptadas para mobile, tablet e desktop
- Boas práticas de **SEO** (Search Engine Optimization)
- Boas práticas de **acessibilidade** (a11y)
- Abordagem de desenvolvimento **mobile-first**

## 🚀 Como executar o projeto localmente

Como se trata de um projeto estático (HTML + CSS), não é necessário instalar dependências. Basta:

```bash
# Clone este repositório
git clone https://github.com/IDuartee8/jornada-viagens.git

# Acesse a pasta do projeto
cd jornada-viagens

# Abra o arquivo index.html no navegador
```

Ou, se preferir, utilize a extensão **Live Server** do VS Code para rodar com recarregamento automático durante o desenvolvimento.
